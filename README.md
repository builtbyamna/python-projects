## Projects

### 1. Appointment Booking System

A web application that allows users to book appointments online.

**Features:**
- Enter your name and email.
- Select a service.
- Choose an appointment date and time.
- Prevent past-date bookings.
- Prevent duplicate appointment times.
- Store appointments in an SQLite database.

**Technologies Used:**
- Python
- Flask
- HTML
- SQLite

**How to Run:**

1. Open the project folder.
2. Install Flask:
   `pip install Flask`
3. Run `main.py`.
4. Open `http://127.0.0.1:5000` in your browser.
